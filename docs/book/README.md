## 算法类
- 《算法导论》：MIT 出版社的经典教材，这是一本由浅入深的好书，堪称“神书”——别看书挺厚，但是对初学者来说很难弄懂的问题也娓娓道来，让人看一遍就明白；而且作者用最简单的英语词汇和句法写书，以至于世界各地的学生们，不需要英语很好，即可读懂原版。只是看完这本大部头之后，总有一些意犹未尽的感觉——对我们日常生活中常见的比如音乐播放器里以及电子游戏里的算法并没有太多介绍
- 《算法设计》：作者 Jon Kleinberg，按照算法的类型或者背后的设计思路来组织内容
- 《算法设计手册》：作者 Steven S. Skiena
- 《算法的乐趣》：王晓华著，算法领域超人气著作
- 《啊哈！算法》：啊哈磊著，算法界的小白书
- 《算法心得：高效算法的奥秘》

## 机器学习
- [《机器学习》](https://book.douban.com/subject/26708119/)：对于那些想把机器学习应用在投资理财上的同学，我和王喆推荐的入门书籍是南京大学周志华老师的《机器学习》。这本书也被叫作“西瓜书”，因为作者在讲解基本术语和原理的时候，经常用挑西瓜来举例子，帮助读者理解。它可以说是国内最流行的机器学习入门书之一，特点就是内容非常全面、详尽，语言也流畅易懂。所以，我把它推荐给机器学习基础还不太牢固的同学，希望它能够带你进入机器学习的大门。
- [《神经网络与深度学习》](https://book.douban.com/subject/35044046/)：对于那些有一定机器学习基础，希望进一步研究的同学，我和王喆推荐阅读复旦大学邱锡鹏老师的《神经网络与深度学习》。这本书也叫“蒲公英书”，它更偏向于介绍神经网络和深度学习，对深度学习的介绍非常全面、详尽，但又不故作高深，是我们进入深度学习领域的绝佳选择。


## 金融投资
- [《富爸爸穷爸爸》](https://book.douban.com/subject/27153484/)：这本书用最本质的方式，讲清楚了什么是资产，例如房子和股票；什么不是资产，例如汽车。它还告诉我们，为什么要扩大自己财产中的资产项，压缩非资产项，以及具体如何去实行。这本书采用了讲故事的方式，对理财新手非常友好，没有任何阅读门槛。读完这本书，你就会明白理财的重要性和大方向，进而走上理财的自驱之路。
- [《漫步华尔街》](https://book.douban.com/subject/10606457/)：《漫步华尔街》是我在刚接触投资的时候看的，但这本书对我的影响非常深刻：它让我放弃了不切实际的投资幻想，回到跟市场一同成长的长期投资轨道上来。整本书里最关键的观点，就是投资指数基金时不要进行过多的个人“瞎操作”。这本书不会教你太多复杂的投资技巧，但是能让你树立正确的投资心态。在我们学习投资的入门阶段，这一点无疑是最关键的。
- [《富可敌国：对冲基金与新精英的崛起》](https://book.douban.com/subject/5914480/)：这本书讲述了全球各类著名对冲基金的发展史，论述深刻，同时又非常有趣。这里面也有不少量化相关的对冲基金，如文艺复兴、D.E.Shaw等。书里涉及了一些金融专业名词，但是描述生动，你可以结合上下文来轻松理解，所以门槛不太高。读完这本书，你可以大致了解各种策略类型的私募基金的相关知识，包括它们在做什么，是怎样做的，谁创造了它们，未来的发展变化，等等。这些知识可以很好地帮助你投资这些私募基金。
- 《巴菲特致股东的信》：投资大师巴菲特每年都会给他投资公司的股东写一封信，介绍当年的投资情况，以及他对市场和公司的观点。这几乎是全世界价值投资者的圣经级教材。巴菲特从来不使用艰深的术语或模型，而是用平实却深刻的语言来讲道理，所以这些资料也基本没有阅读门槛。但是，因为这些信内容丰富，信息量很大，需要你投入大量时间消化理解。如果你有精力，最好是读英文版的。我把中英文版本的资料链接都放在了这里，你可以根据自己的需要来学习。[巴菲特致股东的信（1957至今，中文）](https://xueqiu.com/6217262310/141776956)[巴菲特致股东的信（1977-2020，英文原文）](https://www.berkshirehathaway.com/letters/letters.html)
- [《因子投资：方法与实践》](https://book.douban.com/subject/35192979/)：在我看来，这是近年来最好的讲解多因子模型的专著，不仅思想深刻，表述也准确生动。这本书很适合那些想要深入研究多因子模型，并开发因子投资策略的同学。
- [《主动投资组合管理》](https://book.douban.com/subject/25984361/)：这本书的两位作者是量化投资行业的先驱者，并且都曾经担任BARRA公司的研究总监。它的内容相对较深，描述也偏实践，介绍了许多深刻的真知，书中的很多论述精彩而透彻。这本书被奉为量化组合投资的业界“圣经”。不过，该书有些章节撰写得深度不一，初学者阅读起来可能会觉得吃力。所以我推荐的阅读方法是：首次阅读时，不必纠结看不懂的细节，只要不影响后续阅读就跳过；有一定基础后，再反复阅读本书，每次阅读都会获得新的体会。

### 第一阶段：建立认知与思维（入门推荐）
这个阶段的目标是理解“大数据”是什么、能做什么，建立宏观认知。

-《大数据时代》：作者是维克托·迈尔-舍恩伯格。这本书被誉为大数据领域的“先河之作”，核心思想是“要全体不要抽样、要效率不要绝对精确、要相关不要因果”。它不涉及具体技术，非常适合建立宏观认知和培养数据思维。

### 第二阶段：掌握核心技术（实战入门）
这个阶段要开始动手，掌握具体的开发工具和技术。

- 《Hadoop权威指南》：这本书是大数据领域的“新华字典”，新手必读。它清晰地解释了Hadoop的核心组件，如HDFS（分布式文件系统）和MapReduce（分布式计算模型）的原理。建议重点理解思想，不用死磕源码细节。
- 《Spark快速大数据分析》(Learning Spark)：Spark是目前主流的通用计算引擎。这本书是Spark的“说明书+实战手册”，能帮助你快速掌握RDD、DataFrame等核心概念，从会用spark.sql()进阶到理解其内部机制。
- 《Flink原理与实践》：如果你对实时计算、流处理感兴趣，这本书是很好的国内实战指南。它会深入讲解Watermark、状态管理、Checkpoint等生产环境中的核心概念。
- 《Hive编程指南》：Hive是建立在Hadoop之上的数据仓库工具，允许你用类SQL语句（HiveQL）查询数据。这本书是学习Hive的经典入门书。
- 《Kafka入门与实践》：Kafka是一个高吞吐量的分布式消息队列，是大数据系统中数据管道的关键组件。这本书基于实践，能帮你快速上手。

第三阶段：深入建模与架构（进阶提升）
有一定基础后，需要学习如何设计稳定、高效的数据系统。

- 《数据仓库工具箱》：这本书是维度建模的“圣经”。它系统讲解了事实表、维度表、缓慢变化维等核心概念。如果你不想把数据仓库建成“意大利面条”，这本书是必读的。
- 《大数据之路：阿里巴巴大数据实践》：这本书分享了阿里巴巴内部的大数据实战经验，被誉为“国内实战天花板”。它从数据采集、建模到数据服务、治理，提供了一套可复用的方法论，对于理解大厂的数据体系非常有帮助。
- 《数据密集型应用系统设计》(Designing Data-Intensive Applications)：这本书不讲具体工具，而是深入剖析分布式系统的本质。它探讨了数据一致性、可用性、分区、复制等核心问题，适合有一两年经验后阅读，能帮助你从“码农”思维向“工程师”思维转变。

可以参考以下阅读顺序，由浅入深：1 → 4 → 2 → 5 → 3 → 6。


## 数据分析
- 《精益数据分析·珍藏版》Lean Analytics，人民邮电出版社，2023 年	很推荐，适合入门指标、漏斗、留存和增长。
- 《数据科学中的实用统计学（第 2 版）》Practical Statistics for Data Scientists 2e，人民邮电出版社	很推荐，适合学习转化率、抽样、置信区间和 A/B 测试。
- 《关键迭代：可信赖的线上对照实验》Trustworthy Online Controlled Experiments，机械工业出版社，2021 年	很推荐，适合互联网实验和指标判断。
- 《因果推断：The Mixtape》，Causal Inference: The Mixtape，中国人民大学出版社，2023 年	推荐进阶阅读，适合理解“归因是否等于因果”。
- 《数据密集型应用系统设计》，Designing Data-Intensive Applications，很推荐数据工程方向，覆盖存储、消息、流处理、可靠性和数据系统。新版出版社信息
- 《精通 Web Analytics 2.0》，Web Analytics 2.0，清华大学出版社	可选。内容较早，适合学习数字分析和渠道归因框架，不适合作为 GA4 操作手册。
- 《数据工程基础（影印版）》Fundamentals of Data Engineering，实际上是英文原书影印；有繁体中文正式版	如果英文阅读一般，可以先读《设计数据密集型应用》，再看这本英文或繁体版。影印版信息
- 《网站分析实战——如何以数据驱动决策，提升网站价值》网站数据采集、用户识别、数据清洗、流量来源和广告追踪、虚假流量识别、KPI、用户路径、转化漏斗、用户价值分析
- 《网站数据挖掘与分析》这本比《网站分析实战》更全面，除了指标、流量、用户、路径和转化，还涉及：数据采集与配置、数据体系建设、数据质量、数据管理、营销和运营案例、网站分析工具
- 《数据仓库工具箱（第 3 版）——维度建模权威指南》这本更适合你前面提到的：事件事实表、用户维表、订单事实表、渠道维表、漏斗宽表、指标数据集市、拉链表和历史变化、OLAP 分析模型，对于“埋点数据清洗后如何变成可分析的数据模型”，它非常有帮助。

## 分布式系统
- 《微服务设计（第2版）》：很适合学习服务边界、单体拆分、服务发现、API 演进、Saga、部署和监控。不要把它当“拆服务教程”，重点是理解什么时候不该拆。
- 《解构领域驱动设计》：重点掌握统一语言、子域、限界上下文、聚合、领域事件和上下文映射，用它来划分 OMS、WMS、TMS、结算等边界。
- 《高性能MySQL（第4版）》：Go 服务的绝大多数性能与一致性问题，最后都会落到数据库。重点读索引、事务、锁、查询优化和容量规划。
- 《深入理解分布式系统》｜唐伟志
   中文分布式入门里很值得读的一本，讲系统模型、分区与复制、CAP/PACELC、一致性、Paxos、Raft、分布式事务、时钟问题和典型陷阱。比直接读论文或教材更适合工程开发者。
- 《凤凰架构：构建可靠的大型分布式系统》｜周志明
强烈推荐。它覆盖本地/分布式事务、可靠事件队列、TCC、Saga、共识、服务发现、负载均衡、限流、容错、服务安全、可观测性等，和物流系统的实际开发非常贴近。书中有部分 Java 示例，但核心内容对 Go 一样适用。
- 《分布式系统：概念与设计（原书第5版）》｜Coulouris 等
经典教材，系统性强，适合建立理论框架：进程通信、名字服务、同步、复制、一致性、安全等。中文版较老，不必追逐具体技术实现，重点看基本模型和问题定义。
- 《面向模式的软件架构 卷4：分布式计算的模式语言》
偏硬核，但很有价值。它不是教某个框架，而是解释 Broker、远程代理、发布订阅、分层、负载均衡、容错等模式如何组合。适合作为“设计服务时的参考书”，不建议从头硬啃。
- 《大规模分布式存储系统：原理解析与架构实战》｜杨传辉
偏存储系统，适合进一步理解分布式文件系统、KV 存储、复制、一致性和运维。工具版本较旧，但许多底层取舍仍值得理解
- 《ZooKeeper：分布式过程协同技术详解》。重点理解临时节点、Watch、会话、选主与分布式锁；不要只会调用客户端 API。
- 《Redis设计与实现》。重点看复制、Sentinel、Cluster、持久化、事务和 Lua。书的 Redis 版本较老，但机制讲得很清楚。
- 《Kafka实战》。关注分区、副本、消费组、位点、重复消费、顺序、重试与监控，而不是只学习生产/消费 API。
