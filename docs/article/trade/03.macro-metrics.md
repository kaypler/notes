# 宏观指标

## CPI
**CPI全称 Consumer Price Index（消费者物价指数）**：反映老百姓买东西贵不贵。CPI 过高意味着通胀，央行可能收紧银根（利空）。

日常生活中的鲜菜、鲜果、猪肉、鞋靴服装、医疗用品等价格变动，都体现在这个指标里。一般认为，当**国内CPI低于3%时物价相对平稳；高于3%则被视为通货膨胀**的信号。

CPI为**月度数据**，通常在**次月9日—14日**之间发布，国家统计局（www.stats.gov.cn）通常在发布日上午9:30公布CPI月度报告。

### 参考价值
CPI本身并不直接决定股票涨跌，它的核心参考价值在于引导市场对货币政策走向的预期——而货币政策的变化会通过影响市场流动性和企业融资成本，间接传导至股市。

具体传导逻辑如下：

| CPI状态 | 政策倾向 | 对股市的影响 |
| --- | --- | --- |
| CPI持续走高（通胀压力） | 央行可能加息、提高存款准备金率 | 流动性收紧，企业借贷成本上升，股市估值承压 |
| CPI持续走低（通缩风险） | 央行倾向于降息、宽松货币政策 | 流动性改善，利于股市估值修复 |
| CPI温和上涨 | 经济需求回暖，企业盈利改善 | 通常对股市偏正面 |


## PPI
**PPI全称生产者价格指数（Producer Price Index）**：反映工厂出货价。PPI 领先于 CPI，当 PPI 剧烈上涨而 CPI 不动时，意味着制造业中下游利润被压缩。

PPI为**月度数据**，通常在**次月9日—11日**之间发布，国家统计局（www.stats.gov.cn）通常在发布日上午9:30公布PPI月度报告。

### 参考价值
当PPI进入回升阶段，市场通常会有以下反应：
- **周期类行业受益**：PPI上行往往伴随大宗商品涨价和产能周期回暖，石化、电解铝、油运、工程机械等周期领域可能获得超额收益
- **宽基指数配置价值提升**：当宏观主线从单一行业景气转向价格修复、利润回升和外需韧性共振时，覆盖核心龙头资产的宽基指数配置价值会更加突出
- **独立产业趋势赛道仍有机会**：PPI转正并不意味着所有成长板块走弱，具备独立产业趋势的赛道（如新能源、国防军工、AI产业链等）仍有望获得超额收益


## PMI
**PMI全称采购经理指数（Purchasing Managers' Index）**，经济温度计，景气分水岭：50 是枯荣线。

PMI是一个**环比指标**，反映的是本月比上月的变化情况。指数取值范围在0至100%之间，**50%为扩张与收缩的临界点**——高于50%表示经济活动比上月有所扩张，低于50%表示比上月有所收缩。

### 参考价值
CPI和PPI都在**次月中旬**发布，属于**滞后或同步指标**。而PMI在**当月最后一天**就发布，是每月**第一个出炉的宏观经济数据**，具有突出的**先行性和预测预警作用**。

PMI对股市的指示逻辑很直接：

| PMI状态 | 经济含义 | 对股市的参考意义 |
| --- | --- | --- |
| >50%且上升 | 经济扩张加速 | 企业盈利预期向好，可关注周期板块 |
| >50%但下降 | 经济仍扩张但动能减弱 | 市场可能担忧增长拐点，注意风险 |
| <50%且下降 | 经济收缩加速 | 避险情绪上升，多看少动 |
| <50%但上升 | 收缩减速，底部企稳 | 可能预示经济即将见底，关注布局机会

AI 逻辑：如果 PMI 连续三个月站稳 50 以上且趋势向上，AI 会提高对周期性板块（钢铁、化工、有色）的配置
权重。


## M2
M2全称**广义货币供应量**，是衡量一个国家货币供应总量的重要金融指标。

| 层次 | 名称 | 包含内容 |
| --- | --- | --- |
| M0 | 流通中货币 | 个人持有的现金、企业储备的现金（"掏出来就能用的钱"） |
| M1 | 狭义货币 | M0 + 单位活期存款 + 个人活期存款 + 非银行支付机构客户备付金 |
| M2 | 广义货币 | M1 + 单位定期存款 + 个人定期存款 + 其他存款 |

简单来说，**M2几乎涵盖了一切可能成为现实购买力的货币形式**。它不仅反映现实的购买力（M1部分），还反映潜在的购买力（定期存款等准货币部分），代表了更广泛的经济活动中的货币量。

对A股而言，**M2增速的高低影响股市的"水源"充裕程度，而M2-M1剪刀差则反映了资金是否真正"活起来"**。


## 社融
**社融（社会融资规模）**，是指一定时期内实体经济从金融体系获得的资金总额。通俗地说，它衡量的是整个社会（企业、政府、居民）通过各种渠道"借了多少钱"去投资或消费。

社融由四大类、十余个子项构成：

| 类别 | 具体项目 |
| --- | --- |
| 表内融资 | 人民币贷款、外币贷款 |
| 表外融资 | 委托贷款、信托贷款、未贴现银行承兑汇票 |
| 直接融资 | 企业债券融资、非金融企业境内股票融资 |
| 其他 | 保险公司赔偿、投资性房地产等 |

其中，**人民币贷款是社融的核心组成部分，平均占比超过60%**。

央行每月公布两个口径的数据：**存量**（余额）和**增量**（当月新增规模）。分析社融主要看三个维度：①社融增量的绝对值、②社融存量的同比增速、③社融结构的变化。

### 社融对A股的三个核心影响

#### 1. 社融是股市的"先行信号"
社融备受市场关注，因为它被视为**GDP的先行指标**，可以预测接下来的经济走势。长期市场经验显示，社融数据的好坏会提前1到6个月反映到股市行情中，数据的趋势拐点基本对应股市的高低点。
- **社融持续增长** → 企业融资容易、经济活力提升 → 股市震荡上行
- **社融持续收缩** → 实体经济缺钱、投资受限 → 市场整体偏弱

#### 2. 结构比总量更重要：关键看"钱流向哪里"
光看社融总量远远不够，**结构才是决定板块轮动的核心**。
- **企业中长期贷款增加** → 说明企业对经济预期良好，愿意投资扩产 → 利好大科技、制造业等成长板块
- **居民中长期贷款增加（主要是房贷）** → 反映地产回暖 → 利好地产链、家电、建材
- **政府债券融资高增** → 政府主导基建发力 → 利好基建板块
- **短期贷款、票据融资主导** → 资金未真正进入实体投资，参考意义有限

#### 3. 预期差博弈：超预期 vs 不及预期
社融数据对市场的短期冲击，更多体现在实际值与市场预期的差异上：
- **社融超预期** → 市场情绪提振，短期偏暖
- **社融不及预期** → 短期震荡调整

## LPR
**LPR（贷款市场报价利率）** 是银行贷款定价的参考基准，可以通俗理解为银行给企业放贷的"参考价"。1年期LPR主要对应**短期贷款**（如企业流动资金贷款、个人消费贷等），而5年期以上LPR主要对应**长期贷款**（尤其是房贷）。

LPR的报价机制是：由代表性银行以**公开市场操作利率（主要是7天期逆回购利率）加点**形成报价，每月20日公布。因此，**7天期逆回购利率是LPR的"定价锚"**——政策利率不动，LPR基本不会变。

LPR下调意味着企业贷款利率下降，有助于刺激投资和消费。

## 中国十年期国债收益率
**十年期国债收益率**是中央政府发行、期限为10年的国债在二级市场的到期收益率，通常被视为中国金融市场的**无风险利率基准**，也是各类资产定价的"锚"。

## 美国十年期国债收益率
**美国十年期国债收益率**是美国政府发行、期限为10年的国债在二级市场的到期收益率，被公认为"全球资产定价之锚"。

它之所以如此重要，是因为：
- **全球无风险利率的基准**: 几乎所有风险资产的定价都以其为参照
- **全球资本流动的指挥棒**: 其变动会引发全球资金在不同市场间的重新配置
- **美联储货币政策的传导器**: 反映市场对通胀、经济增长和加息路径的预期

### 参考价值
高利率环境对不同板块股票影响：

| 板块类型 | 对利率的反应 |
|---------|-----------|
| **科技股/成长股** | 对利率最敏感，跌幅通常最大 |
| **价值股/周期股** | 相对抗跌，盈利基本面有支撑 |
| **金融股** | 高利率环境利好息差，相对受益 |

高利率环境对债券影响：
- **旧债贬值**：旧债价格下跌，持有大量旧债的机构（如银行、养老基金）为了止损或应对赎回，往往会**被迫抛售**。这就是为什么加息周期中，往往会出现“**股债双杀**”的局面——债券价格也在跌。
- **利好新入场资金**：加息意味着新发行的债券票息更高。对于手握现金、等待机会的投资者（如保险资金、巴菲特这类巨头），此时买入债券并持有到期，就能锁定几十年来最高的无风险收益。
- **利率顶点**：当市场普遍认为加息已经到顶，甚至预期未来会降息时，当前的利率就是“利率顶点”。此时买入长期国债，不仅能享受当下的高票息，一旦未来降息，债券价格会大幅上涨（**价格与利率反向**），投资者能赚到“**资本利得**”（差价）。所以，**在加息周期的“末期”**，债券往往是即将暴涨的利好资产。


### 美国非农就业数据
**非农就业数据（Non-Farm Payrolls，简称NFP）** 是美国劳工统计局（BLS）每月**第一个星期五美国东部时间上午8:30**发布的一项关键宏观经济指标，用于衡量美国非农业部门就业市场的变化情况。之所以排除农业部门，是因为农业就业受季节、天气等因素影响较大，波动剧烈，难以稳定反映美国经济的真实状态。

非农就业报告通常包含三大核心指标：

| 指标 | 含义 | 市场意义 |
|-----|-----|-----|
| 新增非农就业人数 | 上月新增或减少的非农岗位数量 | 最受关注的头条数据，反映企业扩张意愿 |
| 失业率 | 劳动年龄人口中未找到工作的比例 | 衡量劳动力市场整体健康度 |
| 平均时薪 | 工资增速 | 预示未来通胀压力的领先指标 |

### 不同情境下的市场反应
#### 情景一：非农超预期强劲 → 股市承压
当非农数据显著高于预期，市场逻辑如下：

> 就业强劲 → 居民收入稳定 → 消费需求旺盛 → **通胀压力难降** → 美联储维持高利率甚至加息 → 企业借贷成本上升、估值受压 → **股市下跌**

典型案例：2026年6月5日公布的5月非农新增就业17.2万人，远超市场预期的8.5万人。数据公布后，市场对年底前加息的押注概率从约六成飙升至约98%，纳斯达克指数当日重挫4.18%。

#### 情景二：非农大幅不及预期 → 也可能引发恐慌
当非农数据远低于预期，市场同样可能剧烈下跌——因为投资者担心经济衰退。

典型案例：2024年8月2日公布的7月非农仅新增11.4万人，远低于预期的18.5万人，失业率跳升至4.3%，触发了"萨姆规则"衰退预警。叠加日元套息交易平仓，这份疲软报告成为8月5日全球股市闪崩的导火索。

#### 情景三：数据与预期基本一致 → 市场波澜不惊
当非农数据符合市场预期时，影响相对有限，市场已提前定价。
