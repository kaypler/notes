# 股票技术指标

## 市值 (Market Cap)
**公式：股价 × 总股本**

如果你要把这家公司（比如贵州茅台）整个买下来，需要付多少钱。
- 大盘股（如银行、两桶油）：像大象，稳，但跑得慢。
- 小盘股（如微盘股）：像猴子，跳得高，但容易摔死。


## 净利润增长率
**净利润增长率**告诉你"公司赚钱的速度是变快还是变慢"，但它不告诉你"赚到的钱质量如何、能不能持续"。

真正有价值的分析是：连续3-5年保持中高速增长，且增长主要来自主营业务，同时现金流匹配。

### 计算公式
$$
\text{净利润增长率} = \frac{\text{本期净利润} - \text{上期净利润}}{\text{上期净利润}} \times 100\%
$$


## PE
**PE（市盈率）= 股价 ÷ 每股收益**，也可以理解为 **公司总市值 ÷ 年度净利润**。

它的核心含义是：按目前的盈利水平，你投入的钱需要多少年能回本。

- **高PE（如30倍、50倍以上）**：通常意味着市场对这家公司未来高增长有预期（如科技股、成长股）。但也可能是股价被过度炒作的泡沫。
- **低PE（如5倍、8倍以下）**：可能意味着公司被市场低估（如长期稳定的银行、公用事业股）。但也可能是公司未来前景暗淡、盈利即将下滑，市场给的“便宜是有道理的”。


## PEG
**PEG（市盈率相对盈利增长比率）= PE ÷ 净利润增长率**

它的核心含义是：在考虑公司当前盈利水平的同时，也考虑了其未来的增长速度。PEG越低，说明公司用相对较低的估值获得了较高的增长，性价比越高。

- **PEG < 1**：通常被认为是“被低估”的股票，因为其增长速度超过了当前的估值水平。
- **PEG > 1**：通常被认为是“被高估”的股票，因为其增长速度跟不上当前的估值水平。


## PB
**PB（市净率）= 股价 ÷ 每股净资产**，也可以理解为 **公司总市值 ÷ 股东权益**。

它的核心含义是：按目前的净资产水平，你投入的钱需要多少年能回本。

- PB = 1，说明你花 1块钱买了公司 1块钱的家当。
- PB < 1（破净），说明公司打折卖，通常见于银行、钢铁。


## EPS
**EPS（每股收益）= 净利润 ÷ 总股本**

或者：

**EPS = 股价 / PE**

它反映的是：公司每一股能分到多少利润。


## BPS
**BPS（每股净资产）= 股价 ÷ PB**

它反映的是：公司每一股对应的净资产价值。

## ROA
**ROA（总资产收益率）= 净利润 ÷ 总资产**

它反映的是：公司用全部资产一年能赚回多少钱。数值越高，说明公司资产利用效率越高。

## ROE
**ROE（净资产收益率）= 净利润 ÷ 净资产**

它反映的是：公司用股东投入的每一块钱，一年能赚回多少钱。数值越高，说明公司赚钱效率越高，是巴菲特非常看重的指标。

- **高ROE（如15%-20%以上）**：通常意味着公司有某种护城河（品牌、技术、特许经营权等），是利润的“优等生”。比如一些白酒、家电龙头常年ROE在20%以上。
- **低ROE（如长期低于5%-8%）**：可能处于竞争激烈的行业，或公司经营不善。不过，有些周期型或高速扩张期的公司，ROE可能会暂时性偏低。

> ⚠️ **注意**：ROE需要结合负债率来看。一家公司如果借了大量债务（高负债率），也能把ROE做高，但风险也更高。

### ROE 结合 PE 选股策略
ROE和PE单独使用都有缺陷，最好结合起来看，形成互补：

- **筛选优质候选股：先用ROE**：把ROE长期（比如5-10年）稳定在 15%甚至20%以上 的公司找出来。这能帮你快速排除大量平庸或亏损的公司，聚焦于盈利能力强的企业。
- **确定买入时机：再用PE**：在ROE达标的公司池子里，对比历史PE、行业平均PE。选择在PE处于历史相对低位或合理区间时买入。这就避免了在ROE很高但PE也高得离谱的时候追高接盘。


## 股息率
股息率是一个" backward-looking"**（向后看）**的指标，它告诉你过去分了多少，但不能保证未来。

> 投资价值在于：真正的价值不在于股息率本身的高低，而在于分红的可持续性、公司盈利质量，以及股价是否被低估。

建议结合**股息增长率**（Dividend Growth Rate）一起看——一只股息率3%但每年分红增长10%的股票，长期价值可能远高于股息率6%但分红停滞的股票。

### 计算公式

$$
\text{股息率} = \frac{\text{每股年度股息}}{\text{当前股价}} \times 100\%
$$

或从公司整体角度：

$$
\text{股息率} = \frac{\text{年度分红总额}}{\text{公司总市值}} \times 100\%
$$

举例：某股票股价50元，年度每股分红2.5元，则股息率 = 2.5 ÷ 50 × 100% = 5%

### 关键区分：股息率 vs 分红率
| 指标           | 公式             | 含义                       |
| ------------ | -------------- | ------------------------ |
| **股息率**      | 分红 ÷ 股价        | 投资者视角：买这只股票能获得的**现金回报率** |
| **分红率（派息率）** | 分红 ÷ 每股收益(EPS) | 公司视角：赚到的钱有多少比例分给了股东      |

### 实战参考标准
| 维度          | 参考标准                      |
| ----------- | ------------------------- |
| **合理股息率区间** | A股：2%-5%较为常见；超过6%需警惕风险    |
| **分红率健康区间** | 30%-70%（成熟行业可偏高，科技成长型可偏低） |
| **连续性**     | 优先选择连续5年以上稳定分红或分红增长的公司    |
| **行业对比**    | 银行、公用事业、煤炭、家电等传统行业通常股息率较高 |


## 成交量
成交量的核心价值在于，它是**衡量价格变动真实性和持续性的“燃料表”**。价格是“表象”，而成交量是“本质”。

### 成交量的两大核心参考价值
1. **验证趋势的“真伪”**：价格上涨时成交量放大，说明上涨有资金推动，趋势更可靠；反之，放量下跌则趋势更危险。
2. **识别市场的“拐点”**：价格创新高但成交量萎缩，说明上涨缺乏动力，可能见顶；价格创新低但成交量放大，说明下跌动能增强，可能见底。

### 什么是“量价背离”？
简单说，**量价背离就是价格与成交量的变化方向不一致**。它就像一个预警信号，提示当前趋势的推动力可能正在减弱。

通常分为两种情况：
- **顶背离 (看跌信号)**：价格创新高，但成交量没有同步放大，甚至萎缩。这常发生在上涨趋势末期，意味着追涨力量不足，是股价可能即将见顶回落的警示。
- **底背离 (看涨信号)**：价格创新低，但成交量没有继续放大，反而萎缩或趋于稳定。这常发生在下跌趋势末期，意味着恐慌性抛盘减少，是股价可能即将见底反弹的信号。

### 九种核心量价关系速查

| 量价组合 | 低位 (建仓区) | 中位 (拉升区) | 高位 (出货区) |
|---------|-------------|-------------|-------------|
| 量增价涨 | 主力进场，积极关注 | 趋势健康，坚定持股 | 边拉边出，警惕见顶 |
| 量增价跌 | 主力借利空洗盘，企稳后可低吸 | 多空分歧，破位则离场 | 主力出货，果断离场 |
| 量缩价涨 | 筹码锁定好，主力控盘，持股待涨 | ⚠️ 量价背离，上涨动力不足，警惕回调 | 诱多出货，逢高离场 |
| 量缩价跌 | 抛压耗尽，地量见地价，等待放量 | 洗盘尾声，缩量回踩关键支撑可低吸 | 阴跌不止，坚决远离 |
| 量平价涨 | 买盘稳定，趋势可能延续 | 缺乏爆发力，但趋势尚可 | 多方力量减弱，需警惕 |
| 量平价跌 | 持续卖出，但抛压不重 | 趋势偏弱 | 阴跌，市场无承接 |
| 量增价平 | 主力可能正在吸筹 | 多空激烈交战 | 主力可能对倒出货 |
| 量缩价平 | 成交冷清，方向不明 | 趋势不明，观望 | 市场无人问津，可能继续下跌 |
| 量缩价跌 | 同上（量缩价跌） | 同上（量缩价跌） | 同上（量缩价跌） |


## 换手率
**换手率**（Turnover Rate），也称**周转率**，是指在特定时间内，**某只股票的累计成交股数与其流通股本的比例**。

简单理解就是：市场上“换手”或“转手”买卖该股票的比例。它衡量的是股票交易活跃度的核心指标。

- **高换手率**：意味着股票交易非常活跃，买卖双方分歧大，流动性好。
- **低换手率**：意味着股票交易冷清，关注度低，流动性差。

### 计算公式
计算公式非常简单：

$$
\text{换手率} = \frac{\text{某段时间内的成交量（股）}}{\text{该股票的流通股本（股）}} \times 100\%
$$

- **成交量**：该时间段内成交的总股数。
- **流通股本**：上市公司在市场上可以自由交易的股份总数（扣除限售股）。

**举例**：
某股票流通股本为 1 亿股，今天总共成交了 2000 万股，则当日换手率为：`2000万 / 1亿 × 100% = 20%`。

### 参考价值
区分不同阶段的行情性质

| 股价阶段      |  换手率特征                   | 市场含义                                        |
| :----------  | :-------------------------  | :--------------------------------------------- |
| 低位横盘      |  换手率极低（<1%）             | 无人关注，筹码可能正在被主力悄悄收集。               |
| 温和上涨      |  换手率温和放大（3%-7%）       |  资金开始介入，量价配合健康，上涨有持续性。            |
| 加速拉升      |  换手率持续维持高位（>10%）     |  多空分歧加大，但人气爆棚，短线机会多，风险也逐步累积。  |
| 高位巨量      |  单日换手率突然暴增（>15%-20%） |  很可能是主力在对倒出货，风险极高，需高度警惕。        |
| 下跌初期      |  换手率仍然较高                |  恐慌盘和抄底盘共同作用，但下跌趋势通常难以逆转。      |
| 长期下跌后    |  换手率重新萎缩至极低水平        |  杀跌动能衰竭，可能正在构筑中期底部。                |


## 量比
量比是衡量相对成交量的指标，指股市开市后**平均每分钟的成交量与过去5个交易日平均每分钟成交量之比**。

### 参考价值

| 量比区间 | 市场含义 |
| --- | --- |
| < 0.5 | 严重缩量。缩量创新高说明主力控盘程度高；缩量调整后可能是买入机会 |
| 0.8 ~ 1.5 | 成交量处于正常水平，买卖风险不大，需结合其他指标判断 |
| 1.5 ~ 2.5 | 温和放量。若股价温和上涨，趋势健康可持股；若股价下跌，跌势难止 |
| 2.5 ~ 5 | 明显放量。若配合股价突破重要阻力位，突破有效的概率较高 |
| 5 ~ 10 | 剧烈放量。若在长期低位出现，后续上涨空间大；若在高位出现，需警惕主力出货 |
| 10 ~ 20 | 极端放量。往往是反转信号——高位放量可能见顶，低位放量可能见底 |
| > 20 | 极为少见，多空力量达到极致，趋势可能反向发展 |

### 实战
1. 量比与换手率配合使用
    - **换手率 > 5%，量比在 2~3**：可能是股票启动信号
    - **换手率 5%~10%，量比 3~5**：个股活跃度较高，可能是主升浪征兆
    - **换手率 > 10%，量比 > 5**：低位可能是主力吸筹，高位需警惕出货
    - **换手率 > 5%，量比 < 2**：可能是上涨末期或主力出货，需警惕

2. 关键时间点观察

    有经验投资者会在早上9:45重点关注量比：
    - 量比 < 1.5：参与交易的人少，全天可能走势疲软
    - 量比 > 5（尤其高位）：可能是主力诱导散户接盘，不宜追高

3. 涨停/跌停场景
    - 涨停时量比 < 1：上涨空间可能较大
    - 跌停时量比越小：杀跌动能未充分释放，后市仍有下跌空间


## 均线 (MA)
**均线（Moving Average，简称MA）**，全称移动平均线，是将某只股票（或指数、ETF）过去N个交易日的收盘价加总后除以N，再将每天计算出的平均值连成一条曲线。

简单来说，均线代表了一段时间内市场参与者的平均持仓成本。例如：
- **5日均线（MA5）** = 最近5个交易日收盘价的平均值连线，代表近一周的平均成本
- **20日均线（MA20）** = 最近20个交易日收盘价的平均值连线，代表近一个月的平均成本
- **60日均线（MA60）** = 最近60个交易日收盘价的平均值连线，代表近一个季度的平均成本

均线的核心作用在于**过滤股价的短期随机波动**，把"噪音"抹平，让人看到价格背后更稳定的趋势方向。

### 识别趋势
- **多头排列**：短期均线在上、长期均线在下，从上到下依次排列并向上发散，表明市场处于上升趋势
- **空头排列**：短期均线在下、长期均线在上，依次排列并向下发散，表明市场处于下跌趋势
- **均线缠绕**：多条均线几乎重叠，表明市场处于盘整阶段，方向不明

### 买卖信号
- **金叉**：短期均线从下方上穿长期均线，通常被视为买入信号
- **死叉**：短期均线从上方下穿长期均线，通常被视为卖出信号

### 实战（右侧交易法）
- 选择前期强势股，股价沿5日均线向上推进
- 股价回调时**不跌破20日均线**，或跌破后迅速回升至20日均线上方
- 回调时必须**缩量**，而股价上穿20日线时必须**放量**
- 5日均线重新向上翘头、20日均线逐步走强时，是介入时机


## MACD
**MACD**，全称**指数平滑异同移动平均线**（Moving Average Convergence and Divergence），由美国技术分析大师杰拉德·阿佩尔（Gerald Appel）于1979年提出。它在技术分析领域享有 "**指标之王**" 的称号。

MACD由以下四部分构成：

| 组成部分 | 含义 | 作用 |
| :--- | :--- | :--- |
| DIF快线 | 12日EMA − 26日EMA | 反映短期动能变化，波动灵敏 |
| DEA慢线 | DIF的9日移动平均 | 相对平缓，提供趋势方向参考 |
| 柱状图 | DIF − DEA（红柱为正、绿柱为负） | 表示趋势的"加速度"，柱体收缩意味着动能衰减 |
| 零轴 | 多空分界线 | 零轴之上为多头市场，之下为空头市场

MACD的核心理念可以概括为几个字——"**动能领先于价格**"。它能在趋势真正展开前，通过动能的变化提前传递机会与风险信号。如果说均线告诉你"趋势已经形成"，那么MACD告诉你"趋势正在酝酿或即将改变"。

### 参考价值
1. 判断多空大方向（看零轴）
    - **DIF在零轴上方**：短期均线高于长期均线，市场处于多头环境
    - **DIF在零轴下方**：短期均线低于长期均线，市场处于空头环境

2. 判断买卖时机（看金叉死叉）
    - **金叉**：DIF从下方上穿DEA，代表多头力量正在形成
    - **死叉**：DIF从上方下穿DEA，代表空头力量开始加大

3. 预判趋势反转（看背离）
背离是MACD胜率最高的高阶用法，也是"抄底逃顶"的最强信号：
    - **顶背离**：股价创新高，但MACD（DIF或柱状图）未同步创新高 → 多头力量耗尽，可能见顶
    - **底背离**：股价创新低，但MACD未同步创新低 → 下跌动能衰竭，可能见底

### 买卖信号
**▶ 买入信号（由强到弱）**
| 信号类型 | 具体表现 | 有效性说明 |
| :--- | :--- | :--- |
| 零轴附近金叉 | DIF和DEA在零轴（0轴）位置粘合，随后DIF上穿DEA，同时红柱放出。 | **进可攻、退可守**。零轴代表多空平衡点，在此处金叉意味着股价突破了长期成本线，往往是一波**主升浪的起爆点**。既没有底部的颓势，也没有高位的追涨风险，性价比最高。 |
| 底背离+金叉 | 股价创新低但MACD未创新低，随后出现金叉 | 这是**趋势反转**的最强信号。虽然逆势（左侧）有一定风险，但一旦形成，往往是历史性大底，上涨空间最大。在实战中，背离结构的级别（如周线级别）甚至比金叉本身更重要。 |
| 零轴上方金叉 | DIF在零轴之上相当高的位置，回调后再次上穿DEA。 | 代表强势市场中的回调结束，属于**多头趋势中的空中加油**。胜率尚可（顺势），但位置偏高，如果成交量跟不上，容易形成“二次顶背离”而夭折，盈亏比不如前两者。 |
| 零轴下方金叉 | DIF和DEA均在零轴之下，DIF上穿DEA。 | 这通常只是**超跌反弹**。在大空头趋势下，这种金叉往往被长期均线（如60日线）压制，容易形成“假金叉”或反复缠绕，操作难度大，持续性差。 |
| 柱状图由绿转红 | 仅仅看MACD柱体颜色的变化，而不看DIF与DEA的交叉位置。 | 这是最灵敏但也最不稳定的信号。在震荡市中，柱体可能今天红明天绿，频繁转换。不建议单独作为买卖依据，它更多是用来确认金叉/死叉力度的辅助工具。  

**为什么“零轴附近金叉”比“底背离金叉”更优先？**
你可能会有疑问：不是说背离是最强的吗？这里需要区分“抄底”与“进攻”：
- **底背离金叉（🥈）**：价值在于“预测底部”，爆发力最强，但属于左侧交易。背离之后可能还有背离，若过早介入，可能要承受一段时间的磨底。
- **零轴附近金叉（🥇）**：价值在于“确认趋势”，属于右侧交易。它说明股价已经从底部爬起来，站上了“水面（零轴）”。这时介入，虽然放弃了最低点的那段利润，但确定性最高，资金利用效率最佳。


**▶ 卖出信号（由强到弱）**
| 信号类型 | 具体表现 | 有效性说明 |
| :--- | :--- | :--- |
| 顶背离+死叉 | 股价创出新高（或新高附近），但MACD双线或红柱高度明显低于前一波，随后DIF下穿DEA形成死叉。 | **这是卖出的“圣杯”**。因为它让你卖在**上涨趋势**的**末尾段**，既吃到了大部分主升浪，又精准躲过了随后的暴跌。在A股只能做多的机制下，**“逃顶”的价值远大于“割肉”**，盈亏比最高。 |
| 零轴附近的死叉 | DIF和DEA在高位回调后，回到零轴（0轴）附近，DIF下穿DEA，且绿柱开始放出。 | 这是**多空分界线被跌破**的信号。意味着股价跌破了中期成本线，上涨趋势大概率已经终结，将转入震荡或下跌。这是**清仓出局**的最后良好时机，确定性较高。 |
| 零轴下方死叉 | DIF和DEA均在零轴之下，DIF再次下穿DEA | 这属于“**下跌中继**”或“**加速赶底**”。虽然这是“顺势”看空的信号，但对于持仓者来说，此时股价往往已经跌了很大一段。它的价值在于**强制止损**，避免后续更漫长的阴跌，但滞后性最强，属于“断臂求生”。 |
| 零轴上方死叉 | 股价处于极高位置，DIF在远离零轴的高位下穿DEA。 | 在主升浪中，这种死叉往往是**“空中加油”失败**的回调，但也可能是深度洗盘。信号不稳定，容易被强趋势反包（假死叉）。通常只作为**减仓做差价**（做T）的信号，不建议清仓，否则极易踏空。 |
| 红柱缩短或由红翻绿 | 仅仅看MACD柱体颜色的变化，没有双线交叉配合。 | 同买入端一样，这极度敏感，在震荡市中会反复折腾。若仅凭此卖出，交易磨损会非常大，**绝不能**单独作为清仓依据。

**为什么“顶背离+死叉”比“零轴下方死叉”更优先？**
这恰恰是“买”与“卖”的最大区别：
- **买入时（求稳）**：我们倾向于排在🥇的“零轴附近金叉”，因为那是**右侧确认**，虽然贵一点，但确定性高，拿得安心。
- **卖出时（求狠）**：我们必须把🥇让给“顶背离+死叉”，因为这是左侧逃顶。股票下跌的速度永远比上涨快，**“会买的是徒弟，会卖的是师傅”**。顶背离让你在众人狂热时提前嗅到危险，保住了绝大部分利润；而等到“零轴下方死叉”时，可能已经跌了20%-30%，那时再卖就只剩被动割肉了。

### 局限性
1. 滞后性依然存在
    - MACD虽然比均线灵敏，但本质仍是基于历史数据的滞后指标。金叉出现时，股价可能已经涨了一段；死叉出现时，股价可能已经跌了一段。

2. 震荡市中假信号多
    - 在盘整震荡行情中，金叉死叉会频繁出现，容易让人"两面挨打"。**趋势行情用MACD，震荡行情慎用MACD**。

3. 极强趋势中背离可能失效
    - 在极强上涨趋势中，顶背离可能出现多次但股价继续上涨（即"背离之后还有背离"）。

4. 不要迷信单一指标
    - MACD再强大也只是辅助工具。建议与成交量、均线、KDJ、RSI等指标组合使用，并结合基本面分析。最安全的方式不是追求买在最低点、卖在最高点，而是在感觉"快到位"时分批买入或卖出。


## 布林带
布林带（Bollinger Bands，简称BOLL）是由美国金融分析师约翰·布林格（John Bollinger）在1980年代发明的一种技术分析工具。它结合了移动平均线和标准差两个统计概念，由三条轨道线组成一个带状通道：

| 轨道 | 含义 | 默认计算方式 |
| :--- | :--- | :--- |
| 中轨 | 股价的平均成本 | 20日简单移动平均线（MA20） |
| 上轨 | 压力线（阻力位） | 中轨 + 2倍标准差 |
| 下轨 | 支撑线 | 中轨 − 2倍标准差

### 识别买卖点
- 三线向上买在中轨，卖在上轨
- 三线向下买在下轨，卖在中轨
- 三线走平，下轨买，上轨卖
- 三线张口向上，大牛股赶紧买
- 三线张口向下，垃圾股赶紧卖
- 三线收口，观望不动等方向

### 局限性
| 缺点 | 说明 |
| :--- | :--- |
| 滞后性 | 基于移动平均线计算，信号会滞后于市场价格，在快速变动的市场中尤其明显 |
| 假信号较多 | 在高度波动的市场中，价格可能频繁突破上下轨，产生误导性的买卖信号 |
| 盘整市场失效 | 在无明显趋势的横盘行情中，布林带可能无法提供有效参考 |
| 只关注价格 | 忽略了成交量、市场情绪、宏观经济等其它重要因素

### 实战建议
单独使用布林带容易踩坑，建议与其他指标配合验证：
- 搭配RSI：如果价格创新高但RSI没有同步创新高（顶背离），是卖出预警信号
- 搭配MACD：MACD出现金叉（买入信号）的同时价格冲破中轨，上涨信号更可靠
- 关注成交量：突破时成交量需明显放大（如达到30天平均成交量的2倍以上），否则可能是假突破


## KDJ
KDJ指标中文全称为**随机指标（Stochastic Oscillator）**，由乔治·莱恩（George Lane）在1950年代后期首创，最早用于期货市场分析，后被广泛用于股市的**中短期**趋势判断。

KDJ指标由三条曲线组成：

| 线条 | 名称 | 特点 |
| :--- | :--- | :--- |
| K线 | 快速确认线 | 波动最快，反映股价短期变化 |
| D线 | 慢速主干线 | 相对平缓，反映中期趋势 |
| J线 | 方向敏感线 | 波动最剧烈，可突破0~100区间 |

KDJ的核心计算逻辑是：先计算**RSV（未成熟随机值）**——即当前收盘价在近期价格区间中的相对位置，再通过平滑移动平均计算出K值、D值和J值。常用参数为（9,3,3）。

### 参考价值
1. 超买与超卖判断
    - **超卖区（K、D、J均低于20）**：个股被过度抛售，存在逢低吸纳机会
    - **超买区（K、D、J均高于80）**：个股被过度追捧，需考虑逢高卖出
    - **20~80区间**：市场处于整理状态，建议观望
    - **J线取值更为极端**：J > 100 表示极端超买，股价可能见顶；J < 0 表示极端超卖，短期可能反弹。

2. 金叉与死叉信号
    - **黄金交叉**：K线从下方上穿D线，通常视为买入信号。低位金叉（交叉点在20附近）信号强度更高。
    - **死亡交叉**：K线从上方下穿D线，通常视为卖出信号。高位死叉（交叉点在80附近）信号强度更高。

3. 多空力量判断
    - 当K、D、J三值都在50附近时，多空力量均衡；三值均大于50时，多方占优；均小于50时，空方占优。

### 注意事项
1. **警惕钝化**：在持续单边上涨或下跌行情中，KDJ可能长期处于超买或超卖区域，信号容易失真
2. **适用范围**：对**大盘股**和**热门股**的判断效果较好，不适用于交易不活跃的小盘股
3. **建议组合使用**：可结合MACD、均线系统或趋势线共同研判，提高胜率


## RSI
**RSI（Relative Strength Index，相对强弱指标）**是技术分析中最经典的**动量震荡指标**之一，由韦尔斯·威尔德（Welles Wilder）于1978年提出，用于衡量价格变动的速度和幅度，判断市场是否处于**超买**或**超卖**状态。

RSI 是一个**0-100**之间波动的数值，它通过比较一段时间内**上涨幅度**和**下跌幅度**的比例，来反映买卖双方的力量对比。

| RSI 区间     | 市场含义     |
| ---------- | -------- |
| **80-100** | 严重超买（极强） |
| **70-80**  | 超买区域     |
| **50-70**  | 多头占优     |
| **50**     | 多空平衡点    |
| **30-50**  | 空头占优     |
| **20-30**  | 超卖区域     |
| **0-20**   | 严重超卖（极弱） |

> 传统默认参数是 **14**日，但短线可用 6日或 9日，长线可用 21日。

### 计算逻辑（以14日为例）

RSI 的计算分为三步：

#### 第一步：计算每日价格变动
$$
\text{变动值}=\text{当日收盘价}-\text{前一日收盘价}
$$
- 若变动值 > 0，记为上涨幅度
- 若变动值 < 0，记为下跌幅度（取绝对值）

#### 第二步：计算平均上涨与平均下跌

采用平滑移动平均（Wilder 平滑法，类似指数移动平均）：
$$
\text{平均上涨} = \frac{\text{前日平均上涨} \times 13 + \text{当日上涨}}{14}
$$
$$
\text{平均下跌} = \frac{\text{前日平均下跌} \times 13 + \text{当日下跌}}{14}
$$
  
> 首日计算可用简单算术平均。

#### 第三步：计算 RSI
$$
\text{RS} = \frac{\text{平均上涨}}{\text{平均下跌}}
$$
$$
\text{RSI} = 100 - \frac{100}{1 + \text{RS}}
$$
​
#### 简化理解
- 如果14天内天天上涨，平均下跌为0，RSI = 100
- 如果14天内天天下跌，平均上涨为0，RSI = 0
- 如果涨跌幅度相等，RSI = 50

### RSI 在股票投资中的价值

#### 1. 识别超买与超卖（最基础用法）
- RSI > 70：买方力量过强，可能面临回调（卖出信号）
- RSI < 30：卖方力量过度释放，可能迎来反弹（买入信号）
> ⚠️ 但在强势单边趋势中，RSI 可能长期超买（如牛市）或超卖（如熊市），此时盲目反向操作会被套。

#### 2. 背离信号（最可靠的用法）
背离是 RSI 最有价值的应用，往往预示趋势反转：

| 类型      | 定义               | 含义              |
| ------- | ---------------- | --------------- |
| **顶背离** | 股价创新高，但 RSI 未创新高 | 上涨动能衰竭，**看跌信号** |
| **底背离** | 股价创新低，但 RSI 未创新低 | 下跌动能衰竭，**看涨信号** |

#### 3. 中轴线（50）判断多空趋势
- RSI 持续在 50 上方运行 → 多头市场，宜持股或逢低买
- RSI 持续在 50 下方运行 → 空头市场，宜空仓或逢高卖
- 上穿 50：可能由弱转强
- 下破 50：可能由强转弱

### KDJ与RSI的主要区别
两者都是衡量市场买卖力量强弱的常用工具，核心区别如下：

| 对比维度 | KDJ（随机指标） | RSI（相对强弱指标） |
| --- | --- | --- |
| 核心逻辑 | 当前收盘价在近期价格区间（最高价~最低价）中的**相对位置** | 近期**上涨总幅度与下跌总幅度**的对比 |
| 本质含义 | 价格处于近期箱体的**高低位置** | 市场买卖力量的**强弱程度** |
| 线条数量 | 三条线（K、D、J） | 单条线（通常为一条RSI曲线） |
| 灵敏度 | 更敏感，J线可突破0~100区间 | 相对平缓，始终在0~100之间 |
| 适用场景 | 震荡市中表现更佳 | 趋势判断和强弱分析更直观 |
| 买卖信号 | 金叉/死叉、超买超卖结合 | 超买超卖、形态分析（如M头、W底）|


## ATR
**ATR（Average True Range，平均真实波幅）**是衡量**市场波动性**的核心技术指标，同样由韦尔斯·威尔德（Welles Wilder）提出。与 RSI 不同，ATR **不判断涨跌方向，只衡量价格波动的剧烈程度**。

ATR 反映的是资产价格在一定周期内的**平均波动范围**，数值越大代表波动越剧烈，数值越小代表走势越平缓。

| ATR 状态     | 市场含义                          |
| ---------- | ----------------------------- |
| **ATR 上升** | 波动加剧，多空分歧加大，可能伴随趋势启动或变盘       |
| **ATR 下降** | 波动收敛，市场趋于平静，可能酝酿突破（"暴风雨前的宁静"） |
| **ATR 极低** | 长期横盘，一旦突破往往力度较大               |

> 默认参数通常为 **14** 日，但也可根据交易周期调整为 10日或 20日。

### 计算逻辑（分两步）

#### 第一步：计算真实波幅（TR，True Range）
真实波幅取以下三个值中的最大值：
- 当日最高价−当日最低价
- ∣当日最高价−前一日收盘价∣
- ∣当日最低价−前一日收盘价∣

**为什么要用"真实波幅"而非简单高低点差？**
- 如果当天**跳空高开**或**跳空低开**，简单的高低差会漏掉跳空部分的真实波动
- TR 通过引入前收盘价，确保**跳空缺口**被计入波动

#### 第二步：计算 ATR（平均真实波幅）
对 N 个周期的 TR 取平均：
$$
ATR= \frac{TR_1 + TR_2 + ... + TR_N}{N}
$$
 
实际应用中，更常用平滑移动平均（与 RSI 类似）：
$$
ATR_{\text{今日}} = \frac{ATR_{\text{昨日}} \times (N-1) + TR_{\text{今日}}}{N}
$$
 
#### ​计算示例
假设某股票近3日数据：
- 前收盘价 100元，今日最高 105元，最低 98元
- 则 TR = max(105-98, |105-100|, |98-100|) = max(7, 5, 2) = 7元
- 若前13日 ATR 为 5元，则14日 ATR = (5×13 + 7) / 14 ≈ 5.14元
  
### ATR 在股票投资中的价值

#### 1. 科学设置止损位（最经典用法）
用固定金额止损（如跌5%就割）在波动不同的股票间不公平——一只日均波动3%的股票和一只日均波动0.5%的股票，都用5%止损显然不合理。

ATR 止损法：
- 止损位 = 买入价 - 2×ATR（或 1.5×ATR、3×ATR）
- 逻辑：给价格留出**正常波动空间**，避免被随机噪音洗出

 例如：买入价 100元，ATR=2元，则止损设在 96元（2倍ATR）。若 ATR=5元，则止损设在 90元。

#### 2. 动态仓位管理
ATR 越大，单股风险越高，应降低仓位；ATR 越小，可提高仓位。

$$
\text{可买股数} = \frac{\text{总资金} \times \text{单笔风险比例}}{\text{止损距离}} = \frac{\text{总资金} \times \text{单笔风险比例}}{\text{ATR} \times N}
$$
  
其中：
- 单笔风险比例：你自己定的，比如 1%、2%
- N：ATR 倍数，比如 1.5×ATR、2×ATR、3×ATR（N 越大，止损越宽，仓位越轻）
- 止损距离 = ATR × N

这样让**每单位风险承担相同的资金波动**，实现风险均衡。

#### 3. 识别趋势强度与突破有效性
- 趋势启动：价格突破 + ATR 放大 → 真突破概率高
- 假突破：价格突破但 ATR 萎缩 → 可能是诱多/诱空，缺乏资金跟进
- 趋势衰竭：价格创新高但 ATR 下降 → 动能不足，警惕反转

#### 4. 设定动态止盈目标
与止损对称，可用 ATR 倍数设定止盈：
- 止盈位 = 买入价 + 3×ATR（盈亏比 1.5:1 或 2:1）
- 移动止盈：持仓后每日将止损/止盈位按 ATR 幅度上移，实现让利润奔跑

#### 5. 筛选交易标的
- 短线交易者偏好 ATR 较高的品种（波动大，机会多）
- 中长线投资者或风险厌恶者偏好 ATR 较低且稳定的品种（持仓体验好）

### 实战注意事项
| 注意点             | 说明                                    |
| --------------- | ------------------------------------- |
| **非方向指标**       | ATR 高不代表要涨，也不代表要跌，只代表"波动大"            |
| **跳空影响**        | 财报、政策等导致的跳空会瞬间拉高 ATR，需结合事件判断          |
| **参数敏感**        | 短周期 ATR 反应快但噪音多；长周期更稳定但滞后             |
| **不同品种不可比**     | 高价股（如茅台）的 ATR 绝对值天然高于低价股，应看 ATR/股价的比率 |
| **长期低 ATR 后爆发** | 俗称"波动率压缩"，往往是趋势行情的前兆                  |


## 背离
**背离（Divergence）** 是指股票价格走势与技术指标（如MACD、RSI等）之间出现的不一致现象。简单说就是：**价格在往一个方向走，指标却往相反方向走**。

背离的本质是**市场动能的衰竭**——就像一辆高速行驶的汽车开始减速，虽然车还在往前滑，但动力已经在减弱。

### 如何识别动能衰竭
1. **MACD柱状图缩短**：在上涨趋势中，MACD红柱逐渐缩短，说明上涨动力在减弱
2. **RSI无法创出新高**：价格创新高但RSI在70以上却一峰比一峰低
3. **价格推不动**：股价还在涨，但买单开始接不上，或连续小单却推不动价格
4. **布林线收缩**：布林线的上轨和下轨开始收敛


## 筹码峰
筹码峰（又称筹码分布、移动成本分布）是一张"成本地图"，直观展示不同价位上投资者的持仓数量。它反映的是：**当前持有这只股票的人，分别在什么价位买入、买了多少**。

筹码峰之所以受重视，是因为**K线可以画、成交量可以对倒，但筹码分布是主力用真金白银堆出来的，很难造假**。

### 形态识别
| 形态 | 特征 | 市场含义 |
|------|------|----------|
| 低位单峰密集 | 股价长期下跌/横盘后，筹码在底部狭窄区间高度集中 | 套牢盘大多割肉，主力吸筹充分，是潜在的启动信号 |
| 高位单峰密集 | 股价大涨后，筹码在高位集中 | 主力可能已将筹码派发给散户，需警惕见顶风险 |
| 多峰密集 | 两个或多个价格区间都有筹码峰 | 多空分歧大，股价往往需要震荡消化 |
| 筹码发散 | 筹码分散，无明显密集峰 | 市场混乱，无明显主力控盘，宜观望

单峰越尖越高 → 筹码越集中，主力控盘概率越大。




## 龙虎榜

### 定义 
龙虎榜是沪深证券交易所每个交易日收市后，公布的当日出现交易异常波动的证券名单。榜单的核心内容是：异动股票的交易价格、成交量，以及买入和卖出金额最大的前五家证券营业部（或机构专用席位） 的具体数据。

这一制度的建立初衷是提升市场透明度，为中小投资者打破资金交易的信息壁垒，帮助其了解大资金的实际动向；同时，公开信息披露本身也是一种威慑，便于监管部门快速锁定异动交易背后的资金主体，提升对违法违规交易的查处效率。

### 上榜条件
满足以下任一条件的股票即可上榜，但交易所通常只选取排名前列的股票：

| 上榜条件              |  沪深主板                | 创业板/科创板 |
| :------------------- | :--------------------- | :----------  |
| 涨跌幅偏离值           | 单日≥±7%                |  单日≥±15%   |
| 换手率                | ≥20%                   |  ≥30%        |
| 价格振幅              | ≥15%                    | ≥30%        |
| 连续3日涨跌幅偏离值累计 | ≥±20%                   | ≥±30%        |
| ST/ * ST股票         | 偏离值≥±5%（连续累计±12%） | 要求更严      |

各板块的差异体现了对不同定位的考量：科创板和创业板因本身波动性较高，上榜门槛相应提高；科创板每个条件选取前5名，披露面更广，与其支持硬科技企业的定位相匹配。

### 龙虎榜对投资者的价值（积极面）

#### 1. 揭示主力资金的真实动向
龙虎榜的核心价值在于揭示主力资金的动向和博弈格局。通过榜单，投资者可以了解到哪些资金在买入、哪些在卖出，直观地观察到机构、游资、外资之间的博弈。

#### 2. 判断资金性质，辅助决策逻辑
- **机构集中买入且金额较大**：通常代表专业机构认可该股的中长期价值。机构往往提前做好详细的研究和操盘计划，其行为具有趋势性和一定的前瞻性，机构净买入超过1亿元的个股尤其值得关注。
- **游资席位频繁现身**：往往意味着短线情绪爆发，但也伴随剧烈波动。不同游资的风格迥异，有的擅长"一日游"，有的则善于引导题材行情。
- **机构与游资同步看好**：即"合力榜"，筹码分布相对均衡，上涨动力的持续性可能更强；而单一席位买入过多，形成"一家独大"，后期往往面临抛压风险。

#### 3. 发现市场热点与板块主线
如果某一板块的多只股票频繁登上龙虎榜，说明该板块受到市场的集中关注，大概率是当前阶段的市场主线。投资者可以据此研判市场合力的方向。

#### 4. 结合股价位置判断主力意图
- **股价低位 + 多个机构持续大额买入**：可能是主力在低位吸筹，后续上涨的概率较大；
- **股价高位 + 游资大额买入**：可能是主力在借机出货，风险极高，需高度警惕。
