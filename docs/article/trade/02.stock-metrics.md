# 股票技术指标

## 市值 (Market Cap)
**公式：股价 × 总股本**

如果你要把这家公司（比如贵州茅台）整个买下来，需要付多少钱。
- 大盘股（如银行、两桶油）：像大象，稳，但跑得慢。
- 小盘股（如微盘股）：像猴子，跳得高，但容易摔死。


## 净利润增长率
**净利润增长率**告诉你"公司赚钱的速度是变快还是变慢"，但它不告诉你"赚到的钱质量如何、能不能持续"。

真正有价值的分析是：连续3-5年保持中高速增长，且增长主要来自主营业务，同时现金流匹配。

### 计算公式
$$
净利润增长率= \frac{本期净利润-上期净利润}{上期净利润} \times 100\%
$$


## PE
**PE（市盈率）= 股价 ÷ 每股收益**，也可以理解为 **公司总市值 ÷ 年度净利润**。

它的核心含义是：按目前的盈利水平，你投入的钱需要多少年能回本。

- **高PE（如30倍、50倍以上）**：通常意味着市场对这家公司未来高增长有预期（如科技股、成长股）。但也可能是股价被过度炒作的泡沫。
- **低PE（如5倍、8倍以下）**：可能意味着公司被市场低估（如长期稳定的银行、公用事业股）。但也可能是公司未来前景暗淡、盈利即将下滑，市场给的“便宜是有道理的”。


## PEG
**PEG（市盈率相对盈利增长比率）= PE ÷ 净利润增长率**

它的核心含义是：在考虑公司当前盈利水平的同时，也考虑了其未来的增长速度。PEG越低，说明公司用相对较低的估值获得了较高的增长，性价比越高。

- **PEG < 1**：通常被认为是“被低估”的股票，因为其增长速度超过了当前的估值水平。
- **PEG > 1**：通常被认为是“被高估”的股票，因为其增长速度跟不上当前的估值水平。


## PB
**PB（市净率）= 股价 ÷ 每股净资产**，也可以理解为 **公司总市值 ÷ 股东权益**。

它的核心含义是：按目前的净资产水平，你投入的钱需要多少年能回本。

- PB = 1，说明你花 1块钱买了公司 1块钱的家当。
- PB < 1（破净），说明公司打折卖，通常见于银行、钢铁。


## EPS
**EPS（每股收益）= 净利润 ÷ 总股本**

或者：

**EPS = 股价 / PE**

它反映的是：公司每一股能分到多少利润。


## BPS
**BPS（每股净资产）= 股价 ÷ PB**

它反映的是：公司每一股对应的净资产价值。


## ROE
**ROE（净资产收益率）= 净利润 ÷ 净资产**

它反映的是：公司用股东投入的每一块钱，一年能赚回多少钱。数值越高，说明公司赚钱效率越高，是巴菲特非常看重的指标。

- **高ROE（如15%-20%以上）**：通常意味着公司有某种护城河（品牌、技术、特许经营权等），是利润的“优等生”。比如一些白酒、家电龙头常年ROE在20%以上。
- **低ROE（如长期低于5%-8%）**：可能处于竞争激烈的行业，或公司经营不善。不过，有些周期型或高速扩张期的公司，ROE可能会暂时性偏低。

> ⚠️ **注意**：ROE需要结合负债率来看。一家公司如果借了大量债务（高负债率），也能把ROE做高，但风险也更高。

### ROE 结合 PE 选股策略
ROE和PE单独使用都有缺陷，最好结合起来看，形成互补：

- **筛选优质候选股：先用ROE**：把ROE长期（比如5-10年）稳定在 15%甚至20%以上 的公司找出来。这能帮你快速排除大量平庸或亏损的公司，聚焦于盈利能力强的企业。
- **确定买入时机：再用PE**：在ROE达标的公司池子里，对比历史PE、行业平均PE。选择在PE处于历史相对低位或合理区间时买入。这就避免了在ROE很高但PE也高得离谱的时候追高接盘。


## 股息率
股息率是一个" backward-looking"**（向后看）**的指标，它告诉你过去分了多少，但不能保证未来。

> 投资价值在于：真正的价值不在于股息率本身的高低，而在于分红的可持续性、公司盈利质量，以及股价是否被低估。

建议结合**股息增长率**（Dividend Growth Rate）一起看——一只股息率3%但每年分红增长10%的股票，长期价值可能远高于股息率6%但分红停滞的股票。

### 计算公式

$$
\text{股息率} = \frac{\text{每股年度股息}}{\text{当前股价}} \times 100\%
$$

或从公司整体角度：

$$
\text{股息率} = \frac{\text{年度分红总额}}{\text{公司总市值}} \times 100\%
$$

举例：某股票股价50元，年度每股分红2.5元，则股息率 = 2.5 ÷ 50 × 100% = 5%

### 关键区分：股息率 vs 分红率
| 指标           | 公式             | 含义                       |
| ------------ | -------------- | ------------------------ |
| **股息率**      | 分红 ÷ 股价        | 投资者视角：买这只股票能获得的**现金回报率** |
| **分红率（派息率）** | 分红 ÷ 每股收益(EPS) | 公司视角：赚到的钱有多少比例分给了股东      |

### 实战参考标准
| 维度          | 参考标准                      |
| ----------- | ------------------------- |
| **合理股息率区间** | A股：2%-5%较为常见；超过6%需警惕风险    |
| **分红率健康区间** | 30%-70%（成熟行业可偏高，科技成长型可偏低） |
| **连续性**     | 优先选择连续5年以上稳定分红或分红增长的公司    |
| **行业对比**    | 银行、公用事业、煤炭、家电等传统行业通常股息率较高 |


## 成交量
成交量的核心价值在于，它是**衡量价格变动真实性和持续性的“燃料表”**。价格是“表象”，而成交量是“本质”。

### 成交量的两大核心参考价值
1. **验证趋势的“真伪”**：价格上涨时成交量放大，说明上涨有资金推动，趋势更可靠；反之，放量下跌则趋势更危险。
2. **识别市场的“拐点”**：价格创新高但成交量萎缩，说明上涨缺乏动力，可能见顶；价格创新低但成交量放大，说明下跌动能增强，可能见底。

### 什么是“量价背离”？
简单说，**量价背离就是价格与成交量的变化方向不一致**。它就像一个预警信号，提示当前趋势的推动力可能正在减弱。

通常分为两种情况：
- **顶背离 (看跌信号)**：价格创新高，但成交量没有同步放大，甚至萎缩。这常发生在上涨趋势末期，意味着追涨力量不足，是股价可能即将见顶回落的警示。
- **底背离 (看涨信号)**：价格创新低，但成交量没有继续放大，反而萎缩或趋于稳定。这常发生在下跌趋势末期，意味着恐慌性抛盘减少，是股价可能即将见底反弹的信号。

### 九种核心量价关系速查

| 量价组合 | 低位 (建仓区) | 中位 (拉升区) | 高位 (出货区) |
|---------|-------------|-------------|-------------|
| 量增价涨 | 主力进场，积极关注 | 趋势健康，坚定持股 | 边拉边出，警惕见顶 |
| 量增价跌 | 主力借利空洗盘，企稳后可低吸 | 多空分歧，破位则离场 | 主力出货，果断离场 |
| 量缩价涨 | 筹码锁定好，主力控盘，持股待涨 | ⚠️ 量价背离，上涨动力不足，警惕回调 | 诱多出货，逢高离场 |
| 量缩价跌 | 抛压耗尽，地量见地价，等待放量 | 洗盘尾声，缩量回踩关键支撑可低吸 | 阴跌不止，坚决远离 |
| 量平价涨 | 买盘稳定，趋势可能延续 | 缺乏爆发力，但趋势尚可 | 多方力量减弱，需警惕 |
| 量平价跌 | 持续卖出，但抛压不重 | 趋势偏弱 | 阴跌，市场无承接 |
| 量增价平 | 主力可能正在吸筹 | 多空激烈交战 | 主力可能对倒出货 |
| 量缩价平 | 成交冷清，方向不明 | 趋势不明，观望 | 市场无人问津，可能继续下跌 |
| 量缩价跌 | 同上（量缩价跌） | 同上（量缩价跌） | 同上（量缩价跌） |


## 换手率
**换手率**（Turnover Rate），也称**周转率**，是指在特定时间内，**某只股票的累计成交股数与其流通股本的比例**。

简单理解就是：市场上“换手”或“转手”买卖该股票的比例。它衡量的是股票交易活跃度的核心指标。

- **高换手率**：意味着股票交易非常活跃，买卖双方分歧大，流动性好。
- **低换手率**：意味着股票交易冷清，关注度低，流动性差。

### 计算公式
计算公式非常简单：

$$
换手率 = \frac{某段时间内的成交量（股）}{该股票的流通股本（股）} \times {100\%}
$$

- **成交量**：该时间段内成交的总股数。
- **流通股本**：上市公司在市场上可以自由交易的股份总数（扣除限售股）。

**举例**：
某股票流通股本为 1 亿股，今天总共成交了 2000 万股，则当日换手率为：`2000万 / 1亿 × 100% = 20%`。

### 参考价值
区分不同阶段的行情性质

| 股价阶段      |  换手率特征                   | 市场含义                                        |
| :----------  | :-------------------------  | :--------------------------------------------- |
| 低位横盘      |  换手率极低（<1%）             | 无人关注，筹码可能正在被主力悄悄收集。               |
| 温和上涨      |  换手率温和放大（3%-7%）       |  资金开始介入，量价配合健康，上涨有持续性。            |
| 加速拉升      |  换手率持续维持高位（>10%）     |  多空分歧加大，但人气爆棚，短线机会多，风险也逐步累积。  |
| 高位巨量      |  单日换手率突然暴增（>15%-20%） |  很可能是主力在对倒出货，风险极高，需高度警惕。        |
| 下跌初期      |  换手率仍然较高                |  恐慌盘和抄底盘共同作用，但下跌趋势通常难以逆转。      |
| 长期下跌后    |  换手率重新萎缩至极低水平        |  杀跌动能衰竭，可能正在构筑中期底部。                |

## RSI
**RSI（Relative Strength Index，相对强弱指标）**是技术分析中最经典的**动量震荡指标**之一，由韦尔斯·威尔德（Welles Wilder）于1978年提出，用于衡量价格变动的速度和幅度，判断市场是否处于**超买**或**超卖**状态。

RSI 是一个**0-100**之间波动的数值，它通过比较一段时间内**上涨幅度**和**下跌幅度**的比例，来反映买卖双方的力量对比。

| RSI 区间     | 市场含义     |
| ---------- | -------- |
| **80-100** | 严重超买（极强） |
| **70-80**  | 超买区域     |
| **50-70**  | 多头占优     |
| **50**     | 多空平衡点    |
| **30-50**  | 空头占优     |
| **20-30**  | 超卖区域     |
| **0-20**   | 严重超卖（极弱） |

> 传统默认参数是 **14**日，但短线可用 6日或 9日，长线可用 21日。

### 计算逻辑（以14日为例）

RSI 的计算分为三步：

#### 第一步：计算每日价格变动
$$
\text{变动值}=\text{当日收盘价}-\text{前一日收盘价}
$$
- 若变动值 > 0，记为上涨幅度
- 若变动值 < 0，记为下跌幅度（取绝对值）

#### 第二步：计算平均上涨与平均下跌

采用平滑移动平均（Wilder 平滑法，类似指数移动平均）：
$$
\text{平均上涨} = \frac{\text{前日平均上涨} \times 13 + \text{当日上涨}}{14}
$$
$$
\text{平均下跌} = \frac{\text{前日平均下跌} \times 13 + \text{当日下跌}}{14}
$$
  
> 首日计算可用简单算术平均。

#### 第三步：计算 RSI
$$
\text{RS} = \frac{\text{平均上涨}}{\text{平均下跌}}
$$
$$
\text{RSI} = 100 - \frac{100}{1 + \text{RS}}
$$
​
#### 简化理解
- 如果14天内天天上涨，平均下跌为0，RSI = 100
- 如果14天内天天下跌，平均上涨为0，RSI = 0
- 如果涨跌幅度相等，RSI = 50

### RSI 在股票投资中的价值

#### 1. 识别超买与超卖（最基础用法）
- RSI > 70：买方力量过强，可能面临回调（卖出信号）
- RSI < 30：卖方力量过度释放，可能迎来反弹（买入信号）
> ⚠️ 但在强势单边趋势中，RSI 可能长期超买（如牛市）或超卖（如熊市），此时盲目反向操作会被套。

#### 2. 背离信号（最可靠的用法）
背离是 RSI 最有价值的应用，往往预示趋势反转：

| 类型      | 定义               | 含义              |
| ------- | ---------------- | --------------- |
| **顶背离** | 股价创新高，但 RSI 未创新高 | 上涨动能衰竭，**看跌信号** |
| **底背离** | 股价创新低，但 RSI 未创新低 | 下跌动能衰竭，**看涨信号** |

#### 3. 中轴线（50）判断多空趋势
- RSI 持续在 50 上方运行 → 多头市场，宜持股或逢低买
- RSI 持续在 50 下方运行 → 空头市场，宜空仓或逢高卖
- 上穿 50：可能由弱转强
- 下破 50：可能由强转弱


## ATR
**ATR（Average True Range，平均真实波幅）**是衡量**市场波动性**的核心技术指标，同样由韦尔斯·威尔德（Welles Wilder）提出。与 RSI 不同，ATR **不判断涨跌方向，只衡量价格波动的剧烈程度**。

ATR 反映的是资产价格在一定周期内的**平均波动范围**，数值越大代表波动越剧烈，数值越小代表走势越平缓。

| ATR 状态     | 市场含义                          |
| ---------- | ----------------------------- |
| **ATR 上升** | 波动加剧，多空分歧加大，可能伴随趋势启动或变盘       |
| **ATR 下降** | 波动收敛，市场趋于平静，可能酝酿突破（"暴风雨前的宁静"） |
| **ATR 极低** | 长期横盘，一旦突破往往力度较大               |

> 默认参数通常为 **14** 日，但也可根据交易周期调整为 10日或 20日。

### 计算逻辑（分两步）

#### 第一步：计算真实波幅（TR，True Range）
真实波幅取以下三个值中的最大值：
- 当日最高价−当日最低价
- ∣当日最高价−前一日收盘价∣
- ∣当日最低价−前一日收盘价∣

**为什么要用"真实波幅"而非简单高低点差？**
- 如果当天**跳空高开**或**跳空低开**，简单的高低差会漏掉跳空部分的真实波动
- TR 通过引入前收盘价，确保**跳空缺口**被计入波动

#### 第二步：计算 ATR（平均真实波幅）
对 N 个周期的 TR 取平均：
$$
ATR= \frac{TR_1 + TR_2 + ... + TR_N}{N}
$$
 
实际应用中，更常用平滑移动平均（与 RSI 类似）：
$$
ATR_{今日} = \frac{ATR_{昨日} \times (N-1) + TR_{今日}}{N}
$$
 
#### ​计算示例
假设某股票近3日数据：
- 前收盘价 100元，今日最高 105元，最低 98元
- 则 TR = max(105-98, |105-100|, |98-100|) = max(7, 5, 2) = 7元
- 若前13日 ATR 为 5元，则14日 ATR = (5×13 + 7) / 14 ≈ 5.14元
  
### ATR 在股票投资中的价值

#### 1. 科学设置止损位（最经典用法）
用固定金额止损（如跌5%就割）在波动不同的股票间不公平——一只日均波动3%的股票和一只日均波动0.5%的股票，都用5%止损显然不合理。

ATR 止损法：
- 止损位 = 买入价 - 2×ATR（或 1.5×ATR、3×ATR）
- 逻辑：给价格留出**正常波动空间**，避免被随机噪音洗出

 例如：买入价 100元，ATR=2元，则止损设在 96元（2倍ATR）。若 ATR=5元，则止损设在 90元。

#### 2. 动态仓位管理
ATR 越大，单股风险越高，应降低仓位；ATR 越小，可提高仓位。

$$
\text{可买股数} = \frac{\text{总资金} \times \text{单笔风险比例}}{\text{止损距离}} = \frac{\text{总资金} \times \text{单笔风险比例}}{\text{ATR} \times N}
$$
  
其中：
- 单笔风险比例：你自己定的，比如 1%、2%
- N：ATR 倍数，比如 1.5×ATR、2×ATR、3×ATR（N 越大，止损越宽，仓位越轻）
- 止损距离 = ATR × N

这样让**每单位风险承担相同的资金波动**，实现风险均衡。

#### 3. 识别趋势强度与突破有效性
- 趋势启动：价格突破 + ATR 放大 → 真突破概率高
- 假突破：价格突破但 ATR 萎缩 → 可能是诱多/诱空，缺乏资金跟进
- 趋势衰竭：价格创新高但 ATR 下降 → 动能不足，警惕反转

#### 4. 设定动态止盈目标
与止损对称，可用 ATR 倍数设定止盈：
- 止盈位 = 买入价 + 3×ATR（盈亏比 1.5:1 或 2:1）
- 移动止盈：持仓后每日将止损/止盈位按 ATR 幅度上移，实现让利润奔跑

#### 5. 筛选交易标的
- 短线交易者偏好 ATR 较高的品种（波动大，机会多）
- 中长线投资者或风险厌恶者偏好 ATR 较低且稳定的品种（持仓体验好）

### 实战注意事项
| 注意点             | 说明                                    |
| --------------- | ------------------------------------- |
| **非方向指标**       | ATR 高不代表要涨，也不代表要跌，只代表"波动大"            |
| **跳空影响**        | 财报、政策等导致的跳空会瞬间拉高 ATR，需结合事件判断          |
| **参数敏感**        | 短周期 ATR 反应快但噪音多；长周期更稳定但滞后             |
| **不同品种不可比**     | 高价股（如茅台）的 ATR 绝对值天然高于低价股，应看 ATR/股价的比率 |
| **长期低 ATR 后爆发** | 俗称"波动率压缩"，往往是趋势行情的前兆                  |



## 龙虎榜

### 定义 
龙虎榜是沪深证券交易所每个交易日收市后，公布的当日出现交易异常波动的证券名单。榜单的核心内容是：异动股票的交易价格、成交量，以及买入和卖出金额最大的前五家证券营业部（或机构专用席位） 的具体数据。

这一制度的建立初衷是提升市场透明度，为中小投资者打破资金交易的信息壁垒，帮助其了解大资金的实际动向；同时，公开信息披露本身也是一种威慑，便于监管部门快速锁定异动交易背后的资金主体，提升对违法违规交易的查处效率。

### 上榜条件
满足以下任一条件的股票即可上榜，但交易所通常只选取排名前列的股票：

| 上榜条件              |  沪深主板                | 创业板/科创板 |
| :------------------- | :--------------------- | :----------  |
| 涨跌幅偏离值           | 单日≥±7%                |  单日≥±15%   |
| 换手率                | ≥20%                   |  ≥30%        |
| 价格振幅              | ≥15%                    | ≥30%        |
| 连续3日涨跌幅偏离值累计 | ≥±20%                   | ≥±30%        |
| ST/ * ST股票         | 偏离值≥±5%（连续累计±12%） | 要求更严      |

各板块的差异体现了对不同定位的考量：科创板和创业板因本身波动性较高，上榜门槛相应提高；科创板每个条件选取前5名，披露面更广，与其支持硬科技企业的定位相匹配。

### 龙虎榜对投资者的价值（积极面）

#### 1. 揭示主力资金的真实动向
龙虎榜的核心价值在于揭示主力资金的动向和博弈格局。通过榜单，投资者可以了解到哪些资金在买入、哪些在卖出，直观地观察到机构、游资、外资之间的博弈。

#### 2. 判断资金性质，辅助决策逻辑
- **机构集中买入且金额较大**：通常代表专业机构认可该股的中长期价值。机构往往提前做好详细的研究和操盘计划，其行为具有趋势性和一定的前瞻性，机构净买入超过1亿元的个股尤其值得关注。
- **游资席位频繁现身**：往往意味着短线情绪爆发，但也伴随剧烈波动。不同游资的风格迥异，有的擅长"一日游"，有的则善于引导题材行情。
- **机构与游资同步看好**：即"合力榜"，筹码分布相对均衡，上涨动力的持续性可能更强；而单一席位买入过多，形成"一家独大"，后期往往面临抛压风险。

#### 3. 发现市场热点与板块主线
如果某一板块的多只股票频繁登上龙虎榜，说明该板块受到市场的集中关注，大概率是当前阶段的市场主线。投资者可以据此研判市场合力的方向。

#### 4. 结合股价位置判断主力意图
- **股价低位 + 多个机构持续大额买入**：可能是主力在低位吸筹，后续上涨的概率较大；
- **股价高位 + 游资大额买入**：可能是主力在借机出货，风险极高，需高度警惕。
